# MudMetrics feedback

Public bug reports and feature requests for [MudMetrics](https://mudmetrics.tallin.dev).

[Browse reports](https://github.com/btallin/mudmetrics-feedback/issues) or
[report a bug or request a feature](https://github.com/btallin/mudmetrics-feedback/issues/new/choose).
A GitHub account is required to submit or comment; anyone can read reports.

Reports, comments and attachments are public. Do not include sensitive rider or
personal information, private correspondence, credentials, or unredacted logs.
For private concerns or if you do not have a GitHub account, email
[ben@tallin.dev](mailto:ben@tallin.dev).

This repository contains feedback only. Application source code and internal
implementation tracking remain in a separate private repository.
